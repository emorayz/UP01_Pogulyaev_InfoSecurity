## Назначение и функциональность

WPF-приложение предназначено для учёта информационных активов, инцидентов, рисков, политик безопасности и событий аудита. Реализованы роли «Пользователь» и «Администратор».

- авторизация, регистрация и разграничение ролей;
- хэширование паролей SHA-256;
- капча после трёх неверных попыток входа, запрет копирования и вставки;
- смена пароля с проверкой текущего пароля;
- поиск, фильтрация и сортировка;
- добавление, редактирование и удаление записей администратором в восьми таблицах;
- проверка обязательных полей, диапазонов, форматов и связанных ID;
- подтверждение удаления и выхода, каскадное удаление связанных записей;
- диаграмма распределения инцидентов по статусам;
- экспорт инцидентов в DOCX, PDF и XLSX через Microsoft Office;
- два словаря стилей с сохранением выбранной темы;
- плейсхолдеры, всплывающие подсказки и журналирование действий.

## Структура базы данных

1. `Users` — учётные записи и роли.
2. `Departments` — подразделения организации.
3. `Employees` — сотрудники.
4. `SecurityAssets` — защищаемые информационные активы.
5. `SecurityIncidents` — инциденты информационной безопасности.
6. `RiskAssessments` — оценки рисков.
7. `SecurityPolicies` — внутренние политики безопасности.
8. `AuditEvents` — журнал действий пользователей.

Связи: подразделение содержит сотрудников, активы и политики; актив связывается с инцидентами и оценками рисков; пользователь назначается ответственным за инцидент и создаёт события аудита. Для зависимых сущностей настроено каскадное удаление.

## Запуск

1. Откройте `UP01_Pogulyaev_InfoSecurity/db/schema.sql` в SSMS и выполните скрипт целиком (**Ctrl+A**, затем **F5**). Он создаёт базу `DB_Pogulyaev_InfoSecurity`, восемь таблиц, ограничения, индексы и тестовые данные.
2. Обновите список баз в Object Explorer.
3. Откройте решение `UP01_Pogulyaev_InfoSecurity.sln` в Visual Studio.
4. В `UP01_Pogulyaev_InfoSecurity/App.config` проверьте параметр `data source`. По умолчанию указан `.\SQLEXPRESS`. Для LocalDB замените его на `(localdb)\MSSQLLocalDB`.
5. Восстановите пакеты NuGet, соберите решение и запустите приложение.

## Учётные записи для проверки

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `Admin2026` |

Это демонстрационные учётные записи. Пароли в базе хранятся только в виде SHA-256-хэшей.
